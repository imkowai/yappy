Get started in three steps

1
Get a manager

Install Tampermonkey or another compatible userscript manager.

2
Install the script

Open the manager's install screen and review the script permissions.

3
Open Yapper

Enable the script, visit Yapper and refresh the page.

Other installation options

Your source is hosted as a .txt file. Automatic installer detection isn't guaranteed. You can open the raw source or import the URL in Tampermonkey → Dashboard → Utilities → Import from URL. The download option saves a .user.js filename.

Open raw source ↗

If the installer doesn't appear, use Tampermonkey's Dashboard → Utilities → Import from URL and paste the copied source URL. Alternatively, use Download .user.js and import the downloaded file through your manager. Before enabling it, verify the script's metadata and site permissions.
